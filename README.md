# lunar-rs

Simple implementation of a Lunar Client launcher in Rust.

This research aims to reveal the impact of artificial intelligence on development efficiency, for educational purposes only.

![Videcoding](https://img.shields.io/badge/Videcoding-FF6B00?logo=code&logoColor=white&style=for-the-badge)

## Commands

```bash
# List all local profiles
lunar-rs
lunar-rs list

# Launch a profile (branch defaults to master)
lunar-rs launch <profile-id> [branch]

# Example
lunar-rs launch b27bcb95-025c-4e51-bf5e-956297688823
lunar-rs launch b27bcb95-025c-4e51-bf5e-956297688823 master
```
